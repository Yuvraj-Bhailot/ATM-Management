# 🏧 ATM Management System

A **JDBC-based ATM Management System** developed in Java, using PostgreSQL for database management. The project demonstrates basic ATM and banking operations with database connectivity through **JDBC**.

## ✨ Features

* 🔐 User authentication
* 💰 Balance management
* 💵 Cash withdrawal
* 💳 Cash deposit
* 🔄 Banking transactions
* 🗄️ PostgreSQL database integration

## 🛠️ Tech Stack

* **Java**
* **JDBC**
* **PostgreSQL**
* **Maven**

## 📌 Overview

This project demonstrates how **Java and JDBC** can be used to connect with a PostgreSQL database and implement core ATM functionalities.
